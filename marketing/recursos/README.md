# Recursos

Materia prima para producir piezas. Los archivos pesados (audio, video) no se versionan; acá
queda el orden y la documentación de dónde salió cada cosa.

| Carpeta | Qué va |
|---|---|
| `musica/` | Pistas de fondo. **Registrar la fuente y la licencia de cada una** en `musica/LICENCIAS.md`. Solo Pixabay u otras con licencia clara y sin Content ID. |
| `sonidos/` | Efectos (clics, transiciones, "ding"). Los básicos los sintetiza la skill (`herramientas/sfx.mjs`); acá van los que se consigan aparte. |
| `imagenes/` | Fotos y gráficos de apoyo (productos de ejemplo, rubros, ilustraciones). Confirmar derechos de uso antes de publicar. |
| `capturas/` | Capturas de pantalla del panel/tienda para usar como estáticos o referencias. Usar la demo pública, no datos reales. |
| `tipografias/` | Copias de Geist y Sora si hay que instalarlas para editar (están en `apps/web/public/fonts/`). |

## Convención de nombres

`minusculas-con-guiones`, sin tildes ni espacios. Para música: `artista_titulo_bpm.mp3`
(el BPM ayuda a cortar sobre el ritmo).
