# Guiones

Un archivo por pieza, nombrado `AAAA-MM-DD_slug.md`, copiado de una plantilla:

- [`plantilla-reel.md`](plantilla-reel.md) — reel / short vertical 9:16 (25–35 s).
- [`plantilla-tutorial.md`](plantilla-tutorial.md) — tutorial de una operación real del panel.

Regla de la voz en off: una frase por bloque, hasta 15 palabras, voseo, sin instrucciones de
estilo dentro del texto (el TTS las lee en voz alta). Ver `.claude/skills/videos-tutoriales/`.
